## Findings (most severe first)

### 1. `major` · colors — NULL cell text far below WCAG AA
- **Where:** `/entities/compete.competitions` — all viewports, both color schemes
- **Evidence:** `NULL` renders as `#b6bdc9` on `#ffffff` = **1.89:1** (AA floor is
  4.5:1 for normal text). NULLs are pervasive across nullable columns, so a large
  share of table data is barely legible.
- **Fix:** Darken the null token to ~`#6b7280` (≈4.6:1 on white); keep it
  de-emphasized via italic/weight rather than a near-invisible gray.
  (`styles.css` `.data-table td .null` / `.null`.)

### 2. `major` · responsiveness — undersized touch targets on mobile
- **Where:** `/entities/compete.competitions` — mobile (375px)
- **Evidence:** measured heights — prev/next 33px, search 31px, filter selects
  31px, `+ filter` 29px (all < 44px guideline); in-table sort-header buttons
  18px and cell links (`view` / FK) 16px (< 24px absolute floor).
- **Fix:** min-height 44px on toolbar controls; give in-row links/sort headers a
  ≥24–44px hit area (block padding on links, taller header buttons) on mobile.

### 3. `minor` · themes — no dark support; `prefers-color-scheme: dark` ignored
- **Where:** all pages — dark scheme
- **Evidence:** palette is defined only on bare `:root` with no
  `@media (prefers-color-scheme: dark)` / `[data-theme]` block; dark renders
  pixel-identical to light. Body does paint its own `--bg` (doesn't borrow the
  host), so this is a deliberate but undocumented single-theme choice.
- **Fix:** document light-only intent, or add a dark token set (palette is
  already centralized, so it's low effort).

### 4. `minor` · accessibility — focus indicator is color-only on inputs
- **Where:** search + filter inputs/selects — all viewports
- **Evidence:** `.search-input:focus` / `.filter-builder select:focus` /
  `.filter-value:focus` set `outline: none` and only shift `border-color`
  `#e2e5ea → #2563eb` (1px). The cue is hue-only and low-contrast; other
  controls keep the UA outline, so the affordance is inconsistent.
- **Fix:** replace `outline: none` with a `:focus-visible` ring
  (`box-shadow 0 0 0 2px` accent, or `outline: 2px` with offset).

## Top fixes (highest leverage)

1. **NULL contrast** — one token change, fixes legibility across every table.
2. **Mobile tap targets** — a handful of `min-height`/padding rules on toolbar
   and in-row controls.
3. **Input focus ring** — swap `outline:none` for `:focus-visible`; also closes
   the a11y gap.
4. (Optional) **Dark theme** — add the `prefers-color-scheme: dark` token block.
